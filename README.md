# 🤖 BrandyBot — The Ultimate AI Branding Toolkit

BrandyBot is a state-of-the-art, conversational AI platform designed to transform a simple idea into a complete brand identity in under two minutes. 

Experience a seamless workflow from **Logo Design** to **Brand Guidelines** and **Product Mockups**, all through a powerful AI-driven chat agent.

---

## 🚀 Key Features

- **🤖 Conversational Logo Agent:** Describe your brand vision naturally. Our AI understands context, industry, and personality to design the perfect logo.
- **🎨 50-Line SD Prompts:** Advanced prompt engineering ensures high-fidelity, professional-grade imagery for every generation.
- **📋 Dynamic Brand Guidelines:** Automatically generates a comprehensive style guide including color palettes, typography rationale, and brand voice (Tone, Example Phrases, Do's & Don'ts).
- **👕 Professional Mockup Studio:** Instantly preview your brand on real-world products like business cards, t-shirts, and digital banners.
- **📄 Multi-page PDF Export:** Download clean, high-end Brand Guideline PDFs that adapt to your content length with professional paging.
- **💼 Credit-Based System:** Built-in credit management for both guests and registered users.

---

## 🛠️ Technology Stack

- **Frontend:** React (Vite), JavaScript, Vanilla CSS, Framer Motion (Animations).
- **Backend:** Node.js, Express, PostgreSQL.
- **AI Services:** Gemini 1.5 Flash (for Text & Logic), Stable Diffusion (via AI API for Images).
- **PDF Core:** jsPDF (with custom dynamic layout engine).

---

## 📦 Installation & Setup

### Prerequisites
- Node.js (v18+)
- PostgreSQL Database
- API Keys (Gemini, ImgBB, etc.)

### Backend Setup
1. `cd backend`
2. `npm install`
3. Configure `.env` (use `.env.example` as a template)
4. `npm run dev`

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. Configure `VITE_API_URL` in `.env`
4. `npm run dev`
